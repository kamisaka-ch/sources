# Kamisaka Tools

YouTubeチャンネル「カミサカ」の所有者が、自分のチャンネルの情報と視聴状況を確認するための個人用ツールです。所有者が管理するMac上で使用します。一般向けのアプリ配布や利用者登録は行っていません。

## できること

- YouTube Data APIを使った、チャンネルや動画などの情報の参照。
- YouTube Analytics APIを使った、自分のチャンネルの視聴回数などの分析指標の参照。
- YouTube Reporting APIを使った、利用可能なレポートの確認と分析用レポートの取得。

Googleによる認証では、`youtube.readonly`と`yt-analytics.readonly`の読み取り専用権限を使用します。動画の投稿・編集・削除を行う機能はありません。

## データの取り扱い

取得データは、所有者本人によるチャンネルの確認・分析に使用します。このWebサイトはツールの説明とポリシーを掲載する場所であり、認証情報や非公開の分析結果を掲載しません。

詳しくは[プライバシーポリシー](privacy.html)をご覧ください。
